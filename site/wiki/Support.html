    • Common Issues

    Installation Problems

  • Check Python version (3.8+)
  • Verify PostgreSQL is running
  • Check DATABASE_URL in .env
  • Review Installation Guide

    • Database Issues

  • PostgreSQL must be running
  • Database must exist
  • Check connection string
  • See Database System

    • CSS Not Loading

  • Clear browser cache
  • Verify static folder configuration
  • Check file permissions
  • This was fixed in latest version

    • Authentication Issues

  • Verify email is verified
  • Check password reset token
  • Ensure session is valid
  • See Authentication System

    • Reporting Bugs

    Before Reporting

  • Search existing issues
  • Check documentation
  • Try to reproduce
  • Gather error details

    • Bug Report Template

    1. Description 2. Steps to reproduce 3. Expected behavior 4. Actual behavior 5. Environment details 6. Error messages/logs
