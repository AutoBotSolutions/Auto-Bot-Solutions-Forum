Help
Common Questions

An inactive session is a session that hasn't been used for a period of time. You can set it to automatically log out for security.

Concurrent sessions allow you to be logged in on multiple devices at once. You can limit this number for security.

Device verification adds an extra security step when logging in from a new device or browser.
