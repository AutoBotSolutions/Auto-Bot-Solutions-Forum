## Quick Start Guide

### 🚀 **For New Deployments**

#### 1. System Requirements
```bash
# Minimum Requirements
- Python 3.11+
- PostgreSQL 13+
- Redis 6+
- Elasticsearch 7.x
- 8GB RAM
- 50GB Storage
- Linux (Ubuntu 20.04+ recommended)
```

#### 2. Quick Installation
```bash
# Clone repository
git clone <repository-url>
cd repo-forum

# Run comprehensive setup
chmod +x deploy/dependencies/setup-dependencies.sh
./deploy/dependencies/setup-dependencies.sh

# Start services
./start-dev.sh  # For development
./start-prod.sh # For production
```

#### 3. Verification
```bash
# Test all dependencies
./test-deps.sh

# Verify services
python3 debug_new_systems.py

# Check documentation
ls app/docs/NEW_SYSTEMS_*.md
```

### 🔧 **For Existing Installations**

#### 1. Update Dependencies
```bash
# Update Python packages
pip install --upgrade -r requirements.txt

# Update system services
sudo apt-get update && sudo apt-get upgrade

# Restart services
./restart-all-services.sh
```

#### 2. Apply New Configurations
```bash
# Update configuration files
cp deploy/analytics/analytics-config.yaml /etc/forum/
cp deploy/search/index-config.json /etc/forum/

# Restart affected services
sudo systemctl restart elasticsearch
sudo systemctl restart redis-server
```

#### 3. Verify Integration
```bash
# Run integration tests
python3 -m pytest tests/integration/

# Check system health
python3 debug_new_systems.py

# Monitor performance
curl http://localhost:9090/metrics
```
