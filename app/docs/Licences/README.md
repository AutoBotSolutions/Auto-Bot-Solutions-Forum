## License Comparison

### GPL-3.0 (Copyleft)
- Strong copyleft
- Requires sharing of modifications
- Requires source code distribution
- Can be used in commercial products

### AGPL-3.0 (Network Copyleft)
- Same as GPL-3.0
- Plus network server source code requirement
- Best for web applications
- Strongest copyleft

### LGPL-3.0 (Library Copyleft)
- Weaker copyleft than GPL
- Can be linked with proprietary code
- Library-focused
- Suitable for libraries

### MPL-2.0 (Weak Copyleft)
- File-level copyleft
- Can combine with other licenses
- More permissive than GPL
- Mozilla's choice

### EPL-2.0 (Business-Friendly)
- Weak copyleft
- Patent protection
- Compatible with GPL
- Eclipse Foundation's choice

### CDDL-1.0 (Permissive Copyleft)
- File-level copyleft
- Can be used in proprietary projects
- Sun Microsystems' choice
- Similar to MPL

## Choosing a License

### Choose GPL-3.0 if you want:
- Strong copyleft
- All modifications to be open
- Maximum sharing requirements

### Choose AGPL-3.0 if you want:
- Network server source code requirement
- Strong copyleft for web applications
- Prevent proprietary web service variants

### Choose LGPL-3.0 if you want:
- Allow proprietary linking
- Library-focused licensing
- Weaker copyleft

### Choose MPL-2.0 if you want:
- File-level copyleft
- More permissive than GPL
- Patent protection included

### Choose EPL-2.0 if you want:
- Business-friendly
- Compatible with GPL
- Patent protection
- Eclipse ecosystem

### Choose CDDL-1.0 if you want:
- File-level copyleft
- Similar to MPL
- Can be used in proprietary projects
- Compatible with GPL

## Changing License

To change the license of your project:

1. Choose an appropriate license from this directory
2. Replace the LICENSE.md file with the chosen license
3. Update all source files with the new license notice
4. Notify contributors of the change
5. Ensure you have the right to relicense all contributions

## Important Notes

- Review each license carefully before choosing
- Consider your project's goals and community
- Consult legal counsel if uncertain
- Ensure all contributors agree to license change
- Document the license change in CHANGELOG.md
- Consider dual-licensing for commercial use
